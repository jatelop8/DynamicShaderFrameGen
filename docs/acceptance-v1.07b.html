这一版改了什么（本轮第三成因）

改动为什么
删除 v1.03 的量级逃逸承重 22:02 日志的 #1 acquire proj00=0.149184 证明 世界相机抢到了第一把锁， 是这条逃逸把它走掉的（0.149184 → 1.0 → 0.149184 → … → 0.8391）。 删掉它，锁根本到不了 0.8391。回归 C1：只删逃逸、不带任何释放， 结果已经是 proj00=0.149184 / 世界相机被拒 0 次。
新增 reset-edge 族锁释放补救 治的是另一条入口：开局第一把锁就被菜单族拿到。那条路上 v1.03–v1.06 永远出不来（v1.00 明令异族不得重采）。 回归 C2：只删逃逸时 pub=0（一个快照都发不出去），加释放后恢复。
撤回"still 阈值重采"写出来又丢掉 我第一版加的第三条释放，回归量出它落到 proj00=1（单位正交族）—— 因为采纳的是"恰好第 90 次非连续的那个到达"，谁第 90 个取决于到达顺序。 它只是用错族换错族，还重开了 v1.00 故意关上的门。已撤回，只在回归里留作反证。
异族分支补 ++snapLockStill仪表 原来这条分支 return false 前完全不计数，所以日志里 still=0 是假象， "锁死了多久"根本读不出来。
