3. 死亡前 0.95 秒有一次 LeftAlt，死亡那一刻游戏「丢失焦点」

[13:26:45.648] [INPUT] vk 0x00 -> 0xA4 (2 held, fg=1)
[13:26:46.590] [DMK] WM_ACTIVATEAPP: Game lost focus. Clearing inputs.   ← DirectionalMovement
[13:26:46.590] [DMKUpdate] Received type=LeftAlt value=0 / Sent type=LeftAlt value=0

DirectionalMovement 是往会话里转发按键的模组，它的日志是第三方对「游戏丢焦点」的独立记录。 它自己的最后一行与我们的最后一行相隔 110 ms。

而我必须承认：(2 held) 是我自己的扫描在重复计数。

GetAsyncKeyState 对同一个物理 Alt 会同时报告 VK_MENU (0x12) 与 VK_LMENU (0xA4)；Shift（0x10/0xA0/0xA1）、Ctrl（0x11/0xA2/0xA3）同理。 所以 2 held 时，实际可能只有 一个键 —— 而「第二个键在不在」恰恰决定这一局是 ALT+F4 退出还是ALT 单独按下。又是一个 L61。

4. 我的 [SCREEN] 判据在原理上不成立

74 个采样，每一个都是 distinct=8/8：加载淡出 8/8、菜单 8/8、世界 8/8。

[44082295] [SCREEN] #73 hash=899CCF386BE74EC8 lum=100.93 distinct=8/8 ours=A4110C0648902D2C ourDistinct=5
[44083350] [SCREEN] #74 hash=C0A1CFCA8D01D28C lum=100.93 distinct=8/8 ours=EDCD53D17F0537A5 ourDistinct=6

distinct 数的是「8 个环样本里有几个不同哈希」，而一个横跨任何转变的环， 按构造就是 8 个不同哈希。它在回答「最近八秒里发生过任何事吗」，不是「屏幕有没有变」。 真正重要的那两个采样：lum 一模一样（100.93），哈希不同 —— 这既可能是画面在动， 也可能是世界冻了、只有左上角 FPS 覆盖层在跳。一个哈希分不出来。

另一半：[SCREEN] STALE 要求 sDistinct<=1，而 sDistinct 永远到不了 1 ⇒ 这条判据在世界上一次都不可能触发。第四个「按构造不可能触发」的仪器。

5. v1.31 改了什么（不碰帧生成路径）

#改动为什么
1 屏幕存成图片：每次采样写一个 640×360 BMP 到
<我的文档>\My Games\Skyrim Special Edition\SKSE\DFG_screens\screen_NNN.bmp
环形 96 个文件（自覆盖），文件名进日志		 哈希回答「变了没有」，回答不了「变出来的是不是游戏」。
一张没人找得到的图等于没有图（L58）。
2 判据换成连续样本同一性：same= / oursSame= / dLum=
same>=7 && oursSame<=1 → STALE
same>=3 && oursSame<=1 → FROZEN		 same 才是「画面停住了」的定义；oursSame 是必须的护栏—— 菜单里我们的 colorOut 哈希会连续重复 11 次（1C6B76BA62059E4D）， 没有它就会在菜单里误报。
3 采样 1 Hz → 有 4x 时 2.5 Hz 最近八局世界段 2.0/2.1/2.5/3.0/3.2/4.1/5.7/6.1 秒，1 Hz 只有 2~6 张， 而 same>=3 至少要 3 张。
4 fflush 提到 GDI 捕获之前 原顺序：先把整 tick 的行写完，fflush 在循环末尾； 而 GDI blit 是这个循环里唯一会阻塞的调用 ⇒ 一次阻塞会静默吃掉整个 tick 的读数。 本局本文件最后一行在丢焦点前 110 ms、下一 tick 从未到达，正是这个形状。
5 逐帧（~35 Hz）按键组合检测（挂在 PollHomeKey）： 展开别名、打印真实键集、点名 ALT+F4 (quit) / ALT+TAB (unfocus) / ALT+ENTER / ALT+ESC / CTRL+ESC / F4 1 Hz 采样会整段漏掉一个几百毫秒的按键组合。「进程被杀」和「玩家自己退出」 是两个不同的结论，只有一个是我们的 bug。
6 INPUT_SEEN → INPUT_MOVE_SEEN（必须有能移动角色的键或鼠标动过）， 否则 INPUT_NONMOVE 本局唯一的键是 LeftAlt —— 它不能移动角色 —— 而这一行仍写着 「INPUT_SEEN - a still eyeD here is a frozen world」。拿 Alt 当「世界没响应」的证据，是 L61。
