3. 这次到底改了什么（一句话 + 一个式子）

Streamline.cpp 里计算重投影矩阵时，取逆用的相机和「上一帧」用的相机不是同一台： 取逆用的是引擎那份没有平移的 ViewProj，乘的却是我们自己重建的、含相机位置的矩阵。 两个不同构的矩阵相乘，平移项无法抵消： 

inv( P @ [R|0] )  @  ( P @ [R | -R@eye] )
  = [R^T|0] @ [R | -R@eye]
  = [ I | -eye ]        ← 旋转精确等于单位阵，平移是整个相机位置
                           eye = (-243.05, -415.31, 118.56)  ⇒ 平移量级 ~495

所以 `det3()`（只读 3×3）一直报 1.000000、 看起来完全健康，而 DLSS-G 收到的是一句谎话： 「相机没转，但平移了半个世界」。它据此生成插值帧 → 画面来回。

修法（单点）：取逆改用与「上一帧」同源的矩阵 —— camCurOk ? camCurVP : curForReproj。 相机静止时两边同源，结果精确等于单位矩阵。
