三、★ 新发现：CameraProj 与 CameraProjUnjittered 不可能是一对「抖动/去抖动」

回代码查到，同一个结构体里的两个投影字段被两条不同的链取用：

而这两个字段的值：

样本CameraProj[0][0]CameraProjUnjittered[0][0]关系
19:39 世界（本局）1.19180.83911 / 1.1918 = 0.83907
18:20 世界（正交那局）111 / 1 = 1

而且 18:20 那一份可以整行验证互逆：ProjUnj 把 z 从 [0,1] 映到 [0.1,1] （z' = 0.9z + 0.1），而 Proj 是 z' = 1.1111z - 0.1111 —— 精确互逆。

抖动是亚像素级的：它只会改 [0][0] / [1][1] 的千分之几。 这里是互逆关系、差 42%。⇒ 这两个字段不属于「同一台相机的抖动 / 去抖动」。

但本局不据此改代码：存储序（行主序 / 列主序）在日志里还有歧义， 先把它做成可测量的探针，而不是拿推断去改。
